# Lược đồ quan hệ (Relational Schema) – Các bảng cốt lõi

- **users**(id (PK), email (UK), phone (UK), password_hash, full_name, avatar_url, gender, date_of_birth, is_active, email_verified_at, phone_verified_at, last_login_at, ...)
- **roles**(id (PK), code (UK), name, description)
- **user_roles**(user_id (PK, FK), role_id (PK, FK))
- **addresses**(id (PK), user_id (FK), label, recipient_name, phone, province, district, ward, street, note, latitude, longitude, ...)
- **health_profiles**(user_id (PK, FK), height_cm, weight_kg, target_weight_kg, activity_level, goal, auto_calculate, bmi, bmr, tdee, daily_calorie_target, daily_protein_g, ...)
- **categories**(id (PK), parent_id (FK), name, slug (UK), description, image_url, sort_order, is_active, created_at, updated_at)
- **products**(id (PK), category_id (FK), brand_id (FK), supplier_id (FK), farm_id (FK), name, slug (UK), short_description, description, origin_country, storage_instruction, usage_instruction, ...)
- **product_variants**(id (PK), product_id (FK), sku (UK), barcode (UK), name, net_weight_g, unit_label, price, compare_at_price, cost_price, reorder_level, is_default, ...)
- **nutrition_facts**(product_id (PK, FK), serving_size_g, servings_per_pack, calories_kcal, protein_g, carbohydrate_g, sugar_g, added_sugar_g, fiber_g, fat_g, saturated_fat_g, trans_fat_g, ...)
- **product_batches**(id (PK), variant_id (FK), farm_id (FK), supplier_id (FK), batch_code (UK), qr_code (UK), harvested_on, manufactured_on, expires_on, received_on, quantity_received, unit_cost, ...)
- **warehouses**(id (PK), code (UK), name, province, address, is_cold_storage, is_active)
- **inventory**(id (PK), warehouse_id (FK), batch_id (FK), quantity_on_hand, quantity_reserved, updated_at)
- **carts**(id (PK), user_id (FK), session_token, coupon_id (FK), created_at, updated_at, expires_at)
- **cart_items**(id (PK), cart_id (FK), variant_id (FK), bundle_id (FK), quantity, added_at)
- **orders**(id (PK), order_number (UK), user_id (FK), guest_email, guest_phone, subscription_id (FK), status, payment_status, payment_method, shipping_method_id (FK), address_id (FK), ship_recipient_name, ...)
- **order_items**(id (PK), order_id (FK), product_id (FK), variant_id (FK), bundle_id (FK), batch_id (FK), product_name, variant_name, sku, unit_price, quantity, discount_amount, ...)
- **payments**(id (PK), order_id (FK), method, status, amount, currency, provider_txn_id, paid_at, created_at, updated_at)
- **coupons**(id (PK), code (UK), description, discount_type, discount_value, max_discount_amount, min_order_amount, usage_limit, usage_limit_per_user, used_count, first_order_only, min_tier_id (FK), ...)
- **loyalty_accounts**(user_id (PK, FK), points_balance, lifetime_points, tier_id (FK), updated_at)
- **reviews**(id (PK), product_id (FK), user_id (FK), order_item_id (FK), rating, title, content, is_verified_purchase, status, helpful_count, admin_reply, replied_at, ...)
